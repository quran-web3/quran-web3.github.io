About the Quran Web3 Ecosystem

Quran Web3 is an independent, non-profit full-stack R&D initiative dedicated to exploring serverless, immutable, and highly optimized methods for digital Quranic preservation over public distributed networks.

The Centralized Infrastructure Dilemma

Traditional digital Quran platforms operate on conventional Web2 models. Serving millions of global users through live dynamic database queries incurs massive continuous server infrastructure costs and heavy compute resource bills. Quran Web3 removes centralized server runtime billing entirely by refactoring the system into a static, client-side autonomous architecture.


The 3 Pillars of Our Serverless Manifesto

1. Sovereign User Autonomy

All interactive engagement tools—such as the 365-day automated Khatm scheduler and personal Hifz loops—run privately inside the user's browser local storage sandbox without ever collecting personal emails or tracking user sessions.

2. Censor-Resistant Longevity

The static data capsules utilize immutable cryptographic Content Identifiers (CIDs) on the peer-to-peer IPFS network, rendering the core text permanent and indestructible for future generations regardless of centralized domain updates.

3. Lightweight Performance

Runs on custom-tailored, bare-metal Vanilla JavaScript and clean semantic styles. Animations like the progressive audio playback highlight are handled straight by the device GPU via native CSS properties to eliminate modern framework bloat.

Data Provenance & Architecture Logs

To maintain absolute reliability and transparent authenticity, all script inputs, text elements, and recitation assets are derived directly from verified public sources.

Instead of calling live server database clusters at runtime, our local backend utilizes a custom 10-script Python automation compiler. The master pipeline processes the raw datasets, filters out corrupted audio anomalies, shards text files by Hizb (1-60), encodes audio into minified Base64 text streams distributed across 240 Rub files per Qari, and enforces a client-side RC4 string obfuscation engine split across 4 chunks to block malicious text tampering on open P2P networks.

This ecosystem is built and maintained by a single, independent hobbyist who loves tinkering with code as a self-taught way to learn web engineering.

The project began 3 years ago as a raw, personal sandbox. The early days were completely manual—painstakingly copy-pasting Quranic texts and Tajweed scripts from various sources like Quran NU, and sourcing international translations directly from Tanzil and QuranEnc. As the technical curiosity grew, the development evolved into hunting down bugs on StackOverflow, fetching live endpoints from al-quran.cloud, and eventually reverse-engineering the public API layers of quran.com. This long history of manual migration is why the backend scripts still contain specific, custom logic to convert modern data layers back to legacy formats just to keep the interface running smoothly. When the modern AI era arrived, the development speed accelerated rapidly, allowing this long chain of experimental scripts to finally mature into a stable, serverless production reality.

The platform operates strictly under the cryptographic pseudonym Zamil Hasballah to keep human names out of the picture. The alias itself carries a quiet spiritual manifesto: "Zamil" signifies a companion in service to the global community, while "Hasballah" serves as a permanent anchor reminding the builder that Allah alone is sufficient as the sustainer. By staying anonymous, the focus remains entirely on the purity of the sacred text.
