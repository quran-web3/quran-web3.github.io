Started this journey to see if we can build a Quran app completely independent of central databases. Spent the week reversing the public Quran.com API endpoints to extract the core text blocks and standard translations. Saving raw snapshots locally. Long road ahead.

Zamil Hasballah Dev Log #1 • Inception & Raw Data Extraction

Loading every layout asset on a single page is killing mobile browser frames. Decoupled the header components and Tajweed bar into separate static files. Writing a Vanilla JS engine to fetch them asynchronously via lifecycle hooks. Bandwidth problem solved.

Zamil Hasballah Dev Log #2 • Breaking Up Individual Page Bloat

Discovered the EveryAyah database mirror links. Began writing a Python script to download and parse the raw .mp3 tracks for 6 global reciters. Figuring out how to map standard verse formats dynamically based on page matrix boundaries without breaking client-side load speeds.

Zamil Hasballah Dev Log #3 • Mapping the Audio Matrix

Encountered massive browser memory leak crashes when streaming raw Base64 audio strings directly. Rewrote the handler to dynamically translate arrays into local binary memory Blobs (URL.createObjectURL).

Zamil Hasballah Dev Log #4 • Base64 Sharding & Blob Streams

Tired of apps that force user accounts and email tracking. Designed a localized dashboard engine using localStorage. Bookmarks, private note-taking, and the 365-day algorithmic Khatm schedule charts now run securely inside the user's browser sandbox. Complete privacy by design.

Zamil Hasballah Dev Log #5 • Going 100% Serverless & Offline

Since public P2P network files can be easily cloned, I built a client-side text integrity guard to prevent malicious tampering. Script obfuscation automatically halts and forces a hard-redirect if a fake copy is detected, without triggering false anti-virus flags.

Zamil Hasballah Dev Log #6 • Cryptographic Shield Initialized

The automated 10-script Python pipeline is fully locked, dumping clean static layers directly into parallel frontend tracks (../). Production staging is flying at quranweb3.vercel.app and pinned on IPFS via Lighthouse.
